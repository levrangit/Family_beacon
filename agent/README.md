# Система агентов Family Beacon

Система на основе ИИ для координации задач разработки программного обеспечения с помощью Claude API.

## Обзор

Система агентов построена на архитектуре с несколькими агентами, где каждый агент имеет определенную роль в процессе разработки:

- **Оркестратор** — Координирует задачи разработки и разбивает их на подзадачи
- **Строитель** — Реализует функции на основе плана оркестратора
- **Рецензент** — Проверяет качество кода, безопасность и архитектуру
- **Агент тестирования** — Создает и выполняет тесты

## Архитектура

### Основные компоненты

#### `agents.py`
Предоставляет базовые классы `Agent` и `Runner`:
- **Agent**: Оборачивает Claude API для выполнения задач ИИ с обработкой ошибок
- **Runner**: Управляет выполнением агентов
- **AgentResult**: Структура данных для вывода агентов

**Особенности**:
- Поддержка async/await
- Полная обработка ошибок (подключение, лимиты, ошибки API)
- Логирование для отладки
- Type hints для улучшения качества кода

#### `run.py`
Точка входа для запуска задач оркестратора.

### Модули агентов

#### Оркестратор (`orchestrator/agent.py`)
**Роль**: Координировать задачи разработки

**Ответственность**:
1. Понять запрашиваемую функциональность
2. Проверить структуру проекта
3. Разбить запросы на проверяемые подзадачи
4. Спланировать задачи реализации Строителя
5. Спланировать задачи проверки Рецензента
6. Спланировать задачи валидации Агента тестирования

**Формат вывода**:
- ЦЕЛЬ: Краткое описание функциональности
- ЗАДАЧИ СТРОИТЕЛЯ: Список задач реализации
- ЗАДАЧИ РЕЦЕНЗЕНТА: Проверки кода и безопасности
- ЗАДАЧИ ТЕСТИРОВАНИЯ: Команды тестирования и валидации
- ОЖИДАЕМЫЙ РЕЗУЛЬТАТ: Критерии успеха

**Ограничения**: Режим только для чтения, без изменения файлов

#### Строитель (`builder/agent.py`)
**Роль**: Реализовать функции

**Ответственность**:
1. Проанализировать структуру проекта и паттерны кода
2. Реализовать требуемую функциональность
3. Следовать стилю кода и соглашениям
4. Создавать/изменять файлы по необходимости
5. Обеспечить правильные импорты и зависимости
6. Писать чистый, документированный код
7. Правильно обрабатывать ошибки

**Формат вывода**:
- РЕЗЮМЕ РЕАЛИЗАЦИИ
- ФАЙЛЫ ИЗМЕНЕННЫЕ/СОЗДАННЫЕ
- ДЕТАЛИ РЕАЛИЗАЦИИ
- ВЕРИФИКАЦИЯ Шаги

#### Рецензент (`reviewer/agent.py`)
**Роль**: Проверить реализации

**Ответственность**:
1. Изучить изменения кода
2. Проверить правильность и полноту
3. Проверить на уязвимости безопасности
4. Обеспечить консистентность архитектуры
5. Проверить влияние на производительность
6. Проверить обработку ошибок
7. Валидировать требования

**Формат вывода**:
- РЕЗЮМЕ ПРОВЕРКИ
- КАЧЕСТВО КОДА Оценка
- ПРОВЕРКА БЕЗОПАСНОСТИ
- ПРОВЕРКА АРХИТЕКТУРЫ
- ПРОВЕРКА ПОЛНОТЫ
- РЕКОМЕНДАЦИИ
- СТАТУС ОДОБРЕНИЯ

#### Агент тестирования (`tests/agent.py`)
**Роль**: Создавать и проверять тесты

**Ответственность**:
1. Создать комплексные тестовые случаи
2. Проверить функциональность модульными тестами
3. Протестировать крайние случаи и условия ошибок
4. Проверить интеграцию компонентов
5. Обеспечить требования производительности
6. Валидировать требования проекта

**Формат вывода**:
- РЕЗЮМЕ ТЕСТИРОВАНИЯ
- ПОКРЫТИЕ ТЕСТАМИ
- РЕЗУЛЬТАТЫ ТЕСТОВ
- АНАЛИЗ ОШИБОК
- РЕКОМЕНДАЦИИ
- СТАТУС ОДОБРЕНИЯ

## Установка

```bash
pip install -r requirements.txt
```

## Зависимости

- `anthropic>=0.31.0` — Клиент Claude API
- `python-dotenv>=1.0.0` — Управление переменными окружения

## Конфигурация

Создайте файл `.env` в директории agent:

```env
ANTHROPIC_API_KEY=ваш_ключ_api_здесь
```

## Использование

```bash
python run.py
```

## Обработка ошибок

Система включает полную обработку ошибок:

- **APIConnectionError**: Проблемы подключения к сети
- **RateLimitError**: Превышен лимит API
- **APIError**: Общие ошибки API
- **Логирование**: Все операции логируются для отладки

## Рабочий процесс

1. **Ввод** → Запрос пользователя
2. **Оркестратор** → Анализирует и создает план
3. **Строитель** → Реализует на основе плана
4. **Рецензент** → Проверяет реализацию
5. **Агент тестирования** → Валидирует тестами
6. **Вывод** → Финальный результат
