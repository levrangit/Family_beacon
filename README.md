# Семейный маяк (Family Beacon)

**Семейный маяк** — кроссплатформенная система родительского контроля для настольных компьютеров.  
Приложение помогает родителям мягко направлять цифровую активность ребёнка: отслеживать время за компьютером, устанавливать лимиты на приложения и удалённо управлять устройствами, сохраняя при этом атмосферу заботы и поддержки.

> Метафора бренда: маяк, который освещает безопасный путь в цифровом океане.

## Основные возможности

### Для родителей
- **Обзор** — сводка по всем устройствам, текущему статусу и ключевым метрикам
- **Лимиты** — установка дневных квот и расписаний на приложения и категории + глобальная блокировка устройства
- **История** — детальные логи и визуальные графики времени, проведённого в приложениях (продуктивность / развлечения)
- **Устройства** — мониторинг статуса устройств ребёнка (онлайн/офлайн, уровень батареи) и удалённая блокировка

### Для ребёнка
- Специальный **экран блокировки** при превышении лимитов
- Отображение брендинга «Семейный маяк», причины блокировки и оставшегося времени
- Возможность запросить дополнительное время (в планах)

## Целевая аудитория
- **Родители** — хотят простой и надёжный дашборд для контроля цифровой активности детей
- **Дети** — получают понятные границы без ощущения жёсткого запрета

## Дизайн и бренд
- Чистый, профессиональный и поддерживающий визуальный стиль
- Цветовая система **Guardian Flow** (мягкие синие и нейтральные тона)
- Логотип: стилизованный маяк + дружелюбная типографика
- Полная локализация интерфейса на русский язык

## Технические особенности
- Основной фокус — десктоп (разрешение 1440px и выше)
- Веб-консоль управления + нативный фоновый сервис для мониторинга
- Кроссплатформенность (Windows / macOS / Linux)

## Telegram Bot

Family Beacon предоставляет пользователям Telegram-интерфейс для взаимодействия с системой.

Telegram-бот позволяет пользователю зарегистрироваться или получить доступ к уже существующему профилю, после чего предоставляет интерфейс в соответствии с его ролью.

Для работы Telegram-интеграции используется современная клиентская архитектура на базе MTProto.

### Основные функции

#### 👨 Родитель

Родительский интерфейс предоставляет возможности для:
- управления семейной группой;
- управления профилями детей;
- просмотра состояния устройств;
- управления ограничениями и политиками;
- просмотра необходимой информации о семье;
- взаимодействия с функциями Family Beacon.

#### 👦 Ребёнок

Детский интерфейс предоставляет возможности для:
- доступа к своему профилю;
- просмотра доступной информации;
- взаимодействия с назначенными функциями Family Beacon;
- получения уведомлений и системных сообщений.

### Регистрация

Система поддерживает отдельные сценарии регистрации для родителей и детей.

При регистрации пользователя система связывает его Telegram-профиль с соответствующей учётной записью Family Beacon.

Для присоединения ребёнка к существующей семейной группе используется приглашение.

### Архитектура

Основные компоненты системы:

```text
Telegram
    ↓
Telegram Bot
    ↓
Backend API
    ↓
Supabase
```

Telegram отвечает за пользовательский интерфейс, Backend — за бизнес-логику, а Supabase — за хранение и управление данными системы.

### Обновления

Программные компоненты системы обновляются через автоматизированный release-процесс.

Цель архитектуры — обеспечить:
- контролируемые версии;
- автоматическую проверку релизов;
- безопасное обновление;
- проверку работоспособности;
- возможность отката при проблемах.

Подробности внутренней архитектуры, регистрации, безопасности и процесса обновления являются частью приватной технической документации проекта.
