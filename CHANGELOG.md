# Changelog

Все заметные изменения проекта Family Beacon фиксируются в этом файле.

## [v0.1.0] — 2026-09-05

### Added

- Введена единая система версионирования проекта на основе Semantic Versioning.
- Добавлен корневой файл `VERSION` с текущей версией `0.1.0`.
- Добавлена политика версионирования `docs/VERSIONING.md`.
- Определён формат Git tag версии `vMAJOR.MINOR.PATCH`.
- Определён формат проверенного baseline `baseline-vMAJOR.MINOR.PATCH`.
- Зафиксирован первый официальный уровень версии проекта `v0.1.0`.

### Baseline

```text
baseline-v0.1.0
```

> Примечание: исторический tag `baseline-2026-09-05`, созданный до введения новой системы, сохраняется без переименования.
